# Run Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the local run panel from `docs/superpowers/specs/2026-08-12-run-panel-design.md` — `python -m agent panel` starts an HTTP server on `127.0.0.1:5679` serving a single-page funnel/event-log/history viewer over the agent's existing JSONL event stream, plus the ability to trigger a dry run (with one-off threshold overrides) from the page and watch it stream live.

**Architecture:** A new `agent/panel.py` (stdlib `http.server` + a `ThreadingMixIn` server) serves a single self-contained page (`agent/panel_page.html` — inline CSS, vanilla JS, no build step) and a handful of JSON/SSE routes. A new `agent/funnel.py` holds one pure function that tallies a run's events into per-topic funnel counts — it counts what the agent already decided, never re-filters anything. `agent/main.py`'s `run_dry` is split into a thin CLI wrapper plus a reusable `run_dry_pipeline(topics, run_id=None)` the panel can call directly with topics it has overridden in memory. `agent/main.py`'s `run_real` is **not touched anywhere in this plan** — a parallel work session is actively rewriting it for a different, already-accepted architecture change, and this plan must not collide with that.

**Tech Stack:** Python 3.12 stdlib only (`http.server`, `socketserver`, `threading`, `json`, `re`, `time`, `dataclasses`, `urllib` for verification scripts) — no new dependency. Vanilla JS + inline CSS in the page — no framework, no build step, consistent with the spec's explicit exception to `CLAUDE.md`'s site-wide no-JS rule (this page is not the public static site).

## Global Constraints

- **Bind address is `127.0.0.1:5679` and nothing else, ever.** `POST /run` starts pipeline work with no authentication; a wider bind would expose that to the network. This is the one verification check that must not be skipped, in every task that touches the server. (Spec § Server.)
- **No auth layer, no TLS.** Deliberate — the bind address is the safeguard, not a login form on a single-user local tool. (Spec § Server.)
- **The panel reimplements no filtering/business logic.** It only tallies events the agent's pipeline already emitted (`agent/funnel.py`, and the identical arithmetic mirrored in the page's JS). If the panel can't show something, that's a gap in the event stream, not something to compute independently. (Spec § Purpose.)
- **Overrides are in-memory, single-run, never written to YAML.** `POST /run`'s `overrides` body key produces a modified `TopicConfig` via `dataclasses.replace`, used for exactly one triggered run. The topic YAML files on disk are never touched by the panel. (Spec § Control.)
- **`run_real` is out of scope for every task in this plan.** Only `run_dry`/`main()` in `agent/main.py` are touched. `POST /run` only ever starts dry runs — a `dry_run: false` request is rejected with 400. (This plan's own constraint, not the original spec's — added because a parallel session is mid-rewrite of `run_real` for the accepted `agent-status-widget` architecture; touching that function here would collide with in-flight work.)
- **Single HTML file** (`agent/panel_page.html`), inline CSS, vanilla JS. No framework, no build step — this is a deliberate constraint so a later public-replay page can be a data-source swap, not a rewrite. (Spec § The page.)
- **stdlib `http.server` with a threading mixin.** No dependency beyond what `agent/requirements.txt` already installs. (Spec § Server.)
- **Out of scope, this plan and the original spec agree:** the public replay page, the redaction pass, the export command, authentication, TLS, non-loopback binding, editing topic YAML from the panel, charts beyond the funnel, any change to filtering/pipeline logic.

```python
"""Local monitoring panel — python -m agent panel. Serves a single HTML
page and JSON/SSE endpoints over the agent's JSONL event stream. Binds
only to 127.0.0.1: this process can start pipeline runs, and a wider
bind would expose that to the network."""

from __future__ import annotations

import socketserver
from http.server import BaseHTTPRequestHandler, HTTPServer
from pathlib import Path

HOST = "127.0.0.1"
PORT = 5679

AGENT_DIR = Path(__file__).parent
RUNS_DIR = AGENT_DIR / "runs"
PAGE_PATH = AGENT_DIR / "panel_page.html"


class ThreadingHTTPServer(socketserver.ThreadingMixIn, HTTPServer):
    daemon_threads = True


class PanelHandler(BaseHTTPRequestHandler):
    def do_GET(self) -> None:
        if self.path == "/":
            self._serve_page()
        else:
            self.send_error(404)

    def _serve_page(self) -> None:
        body = PAGE_PATH.read_bytes()
        self.send_response(200)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)


def run_panel() -> None:
    server = ThreadingHTTPServer((HOST, PORT), PanelHandler)
    print(f"Panel running at http://{HOST}:{PORT}/ (Ctrl-C to stop)")
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass
    finally:
        server.server_close()
```

- [ ] **Step 1: Write `agent/funnel.py`**

```python
"""Pure aggregation over a run's JSONL events into per-topic funnel
counts. Counts only what the agent's pipeline already decided — never
recomputes a filter. `scored`/`kept` only mean anything for a real run
(no rank stage exists in a dry run), so `is_real_run` tells the caller
whether those two columns are meaningful."""

from __future__ import annotations


def compute_funnel(events: list[dict]) -> dict:
    is_real_run = any(event.get("stage") == "deliver" for event in events)
    topics: dict[str, dict] = {}

    def topic_entry(slug: str) -> dict:
        return topics.setdefault(
            slug,
            {
                "collected": 0,
                "dated": 0,
                "in_window": 0,
                "new": 0,
                "scored": 0,
                "kept": 0,
                "drops": {},
            },
        )

    for event in events:
        topic = event.get("topic")
        if topic is None:
            continue
        entry = topic_entry(topic)
        stage = event.get("stage")
        kind = event.get("event")
        if kind == "candidate" and stage == "collect":
            entry["collected"] += 1
            entry["dated"] += 1
        elif kind == "drop":
            reason = event["reason"]
            entry["drops"][reason] = entry["drops"].get(reason, 0) + 1
            if stage == "collect":
                entry["collected"] += 1  # undated candidates were still collected

    for entry in topics.values():
        drops = entry["drops"]
        entry["in_window"] = entry["dated"] - drops.get("outside_window", 0)
        entry["new"] = entry["in_window"] - drops.get("seen", 0)
        entry["scored"] = entry["new"] - drops.get("below_relevance", 0)
        entry["kept"] = entry["scored"] - drops.get("over_max_items", 0)

    return {"is_real_run": is_real_run, "topics": topics}
```

- [ ] **Step 4: Add `/runs` and `/runs/<run_id>` to `agent/panel.py`**

```python
"""Local monitoring panel — python -m agent panel. Serves a single HTML
page and JSON/SSE endpoints over the agent's JSONL event stream. Binds
only to 127.0.0.1: this process can start pipeline runs, and a wider
bind would expose that to the network."""

from __future__ import annotations

import json
import re
import socketserver
from http.server import BaseHTTPRequestHandler, HTTPServer
from pathlib import Path

from agent.events import read_events
from agent.funnel import compute_funnel

HOST = "127.0.0.1"
PORT = 5679

AGENT_DIR = Path(__file__).parent
RUNS_DIR = AGENT_DIR / "runs"
PAGE_PATH = AGENT_DIR / "panel_page.html"

RUN_ID_RE = re.compile(r"^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{4}Z$")


class ThreadingHTTPServer(socketserver.ThreadingMixIn, HTTPServer):
    daemon_threads = True


class PanelHandler(BaseHTTPRequestHandler):
    def do_GET(self) -> None:
        if self.path == "/":
            self._serve_page()
        elif self.path == "/runs":
            self._serve_runs_list()
        elif self.path.startswith("/runs/"):
            self._serve_run_detail(self.path[len("/runs/"):])
        else:
            self.send_error(404)

    def _serve_page(self) -> None:
        body = PAGE_PATH.read_bytes()
        self.send_response(200)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def _serve_runs_list(self) -> None:
        runs = []
        for path in sorted(RUNS_DIR.glob("*.jsonl"), reverse=True):
            run_events = read_events(path)
            runs.append(
                {
                    "run_id": path.stem,
                    "event_count": len(run_events),
                    "funnel": compute_funnel(run_events),
                }
            )
        self._send_json(runs)

    def _serve_run_detail(self, run_id: str) -> None:
        if not RUN_ID_RE.match(run_id):
            self.send_error(400, "invalid run id")
            return
        path = RUNS_DIR / f"{run_id}.jsonl"
        if not path.exists():
            self.send_error(404)
            return
        body = path.read_bytes()
        self.send_response(200)
        self.send_header("Content-Type", "application/x-ndjson; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def _send_json(self, data) -> None:
        body = json.dumps(data).encode("utf-8")
        self.send_response(200)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)


def run_panel() -> None:
    server = ThreadingHTTPServer((HOST, PORT), PanelHandler)
    print(f"Panel running at http://{HOST}:{PORT}/ (Ctrl-C to stop)")
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass
    finally:
        server.server_close()
```

- [ ] **Step 1: Replace `agent/panel_page.html` with the funnel view**

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="utf-8">
<title>Research Agent — Run Panel</title>
<style>
  :root { color-scheme: dark; }
  body { background:#141414; color:#e6e6e6; font-family: ui-monospace, "JetBrains Mono", monospace; margin:0; padding:24px; }
  h1 { font-size:16px; text-transform:uppercase; letter-spacing:.08em; color:#7CFC00; margin:0 0 16px; }
  select, button { font-family:inherit; background:#202020; color:#e6e6e6; border:1px solid #333; padding:4px 8px; }
  .funnel-topic { margin-bottom:20px; }
  .funnel-topic h2 { font-size:13px; margin:0 0 6px; color:#e6e6e6; text-transform:uppercase; }
  .funnel-row { display:flex; gap:16px; font-size:13px; flex-wrap:wrap; }
  .funnel-stage { display:flex; flex-direction:column; align-items:center; min-width:48px; }
  .funnel-stage .n { font-size:15px; }
  .funnel-stage .label { color:#888; font-size:11px; }
  .funnel-drop { color:#ff4d4d; cursor:pointer; text-decoration:underline dotted; }
  .drop-detail { display:none; margin-top:6px; padding:8px; background:#0f0f0f; border:1px solid #2a2a2a; font-size:12px; }
  .drop-detail.open { display:block; }
  .drop-item { padding:2px 0; }
</style>
</head>
<body>
  <h1>Run Panel</h1>
  <div>
    <label>Run: <select id="run-select"></select></label>
  </div>
  <div id="funnel-root"></div>

  <script>
  const state = { events: [] };

  const FUNNEL_STAGES = [
    ["collected", "collected", null, null],
    ["dated", "dated", "collect", "undated"],
    ["in_window", "in-window", "date_guard", "outside_window"],
    ["new", "new", "dedupe", "seen"],
  ];
  const REAL_RUN_STAGES = [
    ["scored", "scored", "rank", "below_relevance"],
    ["kept", "kept", "rank", "over_max_items"],
  ];

  function computeFunnel(events) {
    const isRealRun = events.some((e) => e.stage === "deliver");
    const topics = {};
    function entry(slug) {
      if (!topics[slug]) {
        topics[slug] = { collected: 0, dated: 0, in_window: 0, new: 0, scored: 0, kept: 0, drops: {} };
      }
      return topics[slug];
    }
    for (const e of events) {
      if (!e.topic) continue;
      const t = entry(e.topic);
      if (e.event === "candidate" && e.stage === "collect") {
        t.collected += 1;
        t.dated += 1;
      } else if (e.event === "drop") {
        t.drops[e.reason] = (t.drops[e.reason] || 0) + 1;
        if (e.stage === "collect") t.collected += 1;
      }
    }
    for (const t of Object.values(topics)) {
      t.in_window = t.dated - (t.drops.outside_window || 0);
      t.new = t.in_window - (t.drops.seen || 0);
      t.scored = t.new - (t.drops.below_relevance || 0);
      t.kept = t.scored - (t.drops.over_max_items || 0);
    }
    return { isRealRun, topics };
  }

  function dropItemsFor(events, topic, stage, reason) {
    return events.filter((e) => e.event === "drop" && e.topic === topic && e.stage === stage && e.reason === reason);
  }

  function renderFunnel(events) {
    const { isRealRun, topics } = computeFunnel(events);
    const root = document.getElementById("funnel-root");
    root.innerHTML = "";
    const stages = isRealRun ? FUNNEL_STAGES.concat(REAL_RUN_STAGES) : FUNNEL_STAGES;
    for (const [slug, t] of Object.entries(topics)) {
      const section = document.createElement("div");
      section.className = "funnel-topic";
      let row = `<h2>${slug}</h2><div class="funnel-row">`;
      for (const [key, label, dropStage, dropReason] of stages) {
        row += `<div class="funnel-stage"><span class="n">${t[key]}</span><span class="label">${label}</span></div>`;
        if (dropStage && dropReason && t.drops[dropReason]) {
          row += `<div class="funnel-stage"><span class="n funnel-drop" data-topic="${slug}" data-stage="${dropStage}" data-reason="${dropReason}">↓${t.drops[dropReason]}</span><span class="label">${dropReason}</span></div>`;
        }
      }
      row += `</div><div class="drop-detail"></div>`;
      section.innerHTML = row;
      root.appendChild(section);
    }
    root.querySelectorAll(".funnel-drop").forEach((el) => {
      el.addEventListener("click", () => {
        const { topic, stage, reason } = el.dataset;
        const detail = el.closest(".funnel-topic").querySelector(".drop-detail");
        if (detail.classList.contains("open")) {
          detail.classList.remove("open");
          return;
        }
        const items = dropItemsFor(state.events, topic, stage, reason);
        detail.innerHTML = items
          .map((i) => `<div class="drop-item">${i.title} — ${JSON.stringify(i.detail)}</div>`)
          .join("");
        detail.classList.add("open");
      });
    });
  }

  async function loadRuns() {
    const res = await fetch("/runs");
    const runs = await res.json();
    const select = document.getElementById("run-select");
    select.innerHTML = "";
    for (const run of runs) {
      const opt = document.createElement("option");
      opt.value = run.run_id;
      opt.textContent = `${run.run_id} (${run.event_count} events)`;
      select.appendChild(opt);
    }
    select.onchange = () => loadRun(select.value);
    if (runs.length > 0) {
      await loadRun(runs[0].run_id);
    }
  }

  async function loadRun(runId) {
    const res = await fetch(`/runs/${runId}`);
    const text = await res.text();
    state.events = text
      .trim()
      .split("\n")
      .filter(Boolean)
      .map((line) => JSON.parse(line));
    renderFunnel(state.events);
  }

  loadRuns();
  </script>
</body>
</html>
```

    now = datetime.now(timezone.utc)
    if run_id is None:
        run_id = events.new_run_id(now)
    writer = events.EventWriter(run_id)

    state = dedupe.load_state(STATE_PATH)

        all_candidates = []

            if source_name not in topic.sources:

            counts["collected"] += len(candidates) + len(drops)

                dedupe.record_seen(state, candidate, now)

        for drop in drops:

    def _handle_start_run(self) -> None:
        global _active_run_id
        length = int(self.headers.get("Content-Length", 0))
        body = json.loads(self.rfile.read(length)) if length else {}

        if not body.get("dry_run", True):
            self.send_error(400, "only dry runs can be started from the panel")
            return

        with _active_run_lock:
            if _active_run_id is not None:
                self.send_error(409, "a run is already active")
                return
            topics = config.load_topics(TOPICS_DIR, DEFAULTS_PATH)
            topic_filter = body.get("topic")
            if topic_filter:
                topics = [t for t in topics if t.slug == topic_filter]
            overrides = body.get("overrides") or {}
            if overrides:
                topics = [apply_overrides(t, overrides) for t in topics]

            run_id = events.new_run_id(datetime.now(timezone.utc))
            _active_run_id = run_id
            thread = threading.Thread(target=self._execute_run, args=(topics, run_id), daemon=True)
            thread.start()

        self._send_json({"run_id": run_id})

    def _execute_run(self, topics: list, run_id: str) -> None:
        global _active_run_id
        try:
            run_dry_pipeline(topics, run_id=run_id)
        finally:
            with _active_run_lock:
                _active_run_id = None
